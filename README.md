# hello-git

我的第一个 Git 仓库。

## 这个仓库是干什么的

用来走通 Git 的完整流程：从本地提交，到推送到 GitHub。

## 我在这次练习里学到的东西

- `git init` —— 把普通文件夹变成 Git 仓库
- `git add` —— 把改动放进暂存区
- `git commit` —— 把暂存区的内容存成一个历史版本
- `git remote add` —— 告诉本地仓库「远程仓库在哪」
- `git push` —— 把本地提交上传到 GitHub

## 常用命令备忘

| 命令 | 作用 |
| --- | --- |
| `git status` | 看当前有哪些改动还没提交 |
| `git log --oneline` | 看提交历史（一行一条） |
| `git diff` | 看具体改了哪几行 |
| `git push` | 把本地提交推到 GitHub |
| `git pull` | 把 GitHub 上的新内容拉下来 |

## 环境

- Git 2.56.1
- 通过 SSH 连接 GitHub（`ssh.github.com:443`）
